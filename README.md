## Problems Completed

### 1. Mini-Max Sum

**Approach:**  
Calculate the total sum of all elements. The minimum sum is obtained by subtracting the maximum element from the total, while the maximum sum is obtained by subtracting the minimum element.

**Time Complexity:** O(N)

**Auxiliary Space:** O(1)

**Folder:** `01-Mini-Max-Sum`

---

### 2. Birthday Cake Candles

**Approach:**  
Find the tallest candle using `max()` and count how many times that height occurs using `count()`.

**Time Complexity:** O(N)

**Auxiliary Space:** O(1)

**Folder:** `02-Birthday-Cake-Candles`

---

### 3. Insertion Sort – Part 1

**Approach:**  
Store the last element as the value to be inserted. Compare it with the elements before it and shift larger elements one position to the right until the correct position is found.

**Time Complexity:** O(N) for the required single insertion operation.

**Auxiliary Space:** O(1)

**Folder:** `03-Insertion-Sort-Part-1`

---

### 4. Binary Search

**HackerRank Challenge:** Intro to Tutorial Challenges

**Approach:**  
Use two pointers, `low` and `high`, to represent the current search range. Find the middle element and compare it with the target. If the target is larger, search the right half; otherwise, search the left half.

**Time Complexity:** O(log N)

**Auxiliary Space:** O(1)

**Folder:** `04-Binary-Search`

---

### 5. Mark and Toys

**Approach:**  
Sort the toy prices in ascending order and purchase the cheapest toys first while the total cost remains within the available budget.

**Time Complexity:** O(N log N)

**Auxiliary Space:** O(N) for Python's sorting implementation.

**Folder:** `05-Mark-and-Toys`
